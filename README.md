# 🔐 CryptoHack Solutions & Cryptography Analysis

*Place to document solutions, ideas and answers to cryptographic challenges.*

## 🎯 Overview
This repository serves as a personal knowledge base, write-up collection, and mathematical analysis log for my journey through [CryptoHack](https://cryptohack.org/). It contains scripts, theoretical notes, and practical implementations demonstrating how to exploit various cryptographic vulnerabilities.

## 📂 Repository Structure
The directories are organized to mirror the platform's core learning modules:

* `Introduction/`: Data formats, encoding schemes (Base64, Hex), and XOR operations.
* `Mathematics/`: Modular arithmetic, greatest common divisors (GCD), and brainteasers.
* `Symmetric_Ciphers/`: AES implementations, block cipher modes of operation (ECB, CBC), and padding attacks.
* `RSA/`: Factoring algorithms, padding oracles, and public-key cryptography weaknesses.
* `Elliptic_Curves/`: ECDLP, curve math, and signature forging.

## 🛠️ Tools & Technologies
Most of the challenges here are solved using standard cryptographic analysis tools and scripting:
* **Language:** Python 3
* **Libraries:** `PyCryptodome`, `pwntools`, `requests`, `math`
* **Advanced Math:** [SageMath](https://www.sagemath.org/) (for complex algebraic and lattice-based challenges)

## ⚠️ Spoiler Warning
This repository contains explicit, working solutions to CryptoHack challenges. If you are currently learning on the platform, I highly encourage you to read the provided material and try to solve the challenges on your own before looking at these scripts. The true value of cryptography is in the struggle!
